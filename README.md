# ทองพอร์ต

เว็บแอปส่วนตัวสำหรับติดตามทองคำแท่งและทองรูปพรรณ 96.5% ด้วย Dashboard, CRUD และการคำนวณมูลค่า/กำไรขาดทุนโดยประมาณจากราคาประกาศสมาคมค้าทองคำที่ดึงอัตโนมัติเมื่อเปิดแอปและทุก 2 นาทีขณะเปิดใช้งาน ฟอร์มซื้อเข้าแนบรูปทองและใบรับประกัน (ภาพ/PDF) ได้ โดยเก็บในอุปกรณ์และรวมในไฟล์สำรอง; แบบฟอร์มใช้สีทอง–แดง ส่วนหน้า Overview ยังใช้ธีมทอง–แดงตามที่ออกแบบ และแท็บอื่นยังใช้ธีมเดิม

ภาพ Preview: Dashboard `dashboard-theme-gold-red-desktop.png` และ `dashboard-theme-gold-red-mobile.png`; หน้าฟอร์มซื้อเข้า `add-transaction-form-preview.webp`.

## การตัดสินใจด้านราคา/ข้อมูล

- มี Node server เฉพาะ proxy ราคาสาธารณะจากสมาคมฯ เพราะ upstream ไม่เปิด CORS; ไม่เปิด cloud database และ server ไม่ได้รับรายการทอง/ต้นทุน/รูปภาพ/ใบรับประกัน
- รายการทอง รูป/เอกสาร และ quote ล่าสุดเก็บใน IndexedDB ของ browser เครื่องที่ใช้อยู่; ไม่มีบัญชีหรือ cloud sync
- รูปและเอกสารรับประกันเก็บใน record ของ IndexedDB ไม่อัปโหลดขึ้น server; รูปถูกปรับขนาดก่อนเก็บ, PDF จำกัด 5 MB และไฟล์ backup รุ่นเดิมที่ไม่มี attachments ยังนำเข้าได้
- ดึงราคาทองแท่งรับซื้อ/ขายออกและรูปพรรณฐานภาษี/ขายออกจาก endpoint ทางการ; เวลาเผยแพร่ของสมาคมฯ แสดงแยกจากเวลาที่ดึงข้อมูล
- เมื่อเชื่อมต่อไม่ได้ ใช้ quote ล่าสุดในเครื่องและแจ้งสถานะ; ผู้ใช้กรอกราคาสำรองได้ โดยราคาทางการจะกลับมาเป็นค่าหลักเมื่อเชื่อมต่อสำเร็จครั้งถัดไป
- ส่งออก/นำเข้าข้อมูลสำรอง JSON; ควรสำรองก่อนล้าง browser หรือเปลี่ยนอุปกรณ์
- ดูแผนพัฒนาและข้อควรทราบที่ `plan.md`, `BUILD-PLAN.md` และ `PRICE-SOURCE.md`

## คำสั่ง

- `pnpm dev` — เปิด development preview ที่ port 3000
- `pnpm build` — ตรวจ TypeScript และสร้าง static output ใน `dist/`
- `pnpm start` — เริ่ม production Node API/static server (ตั้ง `PORT` ได้)
- `pnpm preview` — serve production build เพื่อ QA

แอปยังไม่เผยแพร่สู่ public hosting; เปิดดูผ่าน Preview ของโปรเจกต์ใน Manus
